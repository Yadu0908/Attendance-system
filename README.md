# Smart Attendance Management System

Pre-Drive Product Engineering Assignment - Edumerge Solutions

## Overview

A comprehensive web application designed for educational institutions to manage student attendance, track low-attendance defaulters automatically, and provide dedicated portals for Faculty, Administrators, and Students.

---

## Project Structure

src/
├── context/
│ └── ThemeContext.jsx # useContext for Theme (Dark/Light)
├── data/
│ └── mockData.js # LocalStorage Caching helper + Initial Data
├── components/
│ ├── Navbar.jsx # Navigation, Role switcher & Theme Toggle
│ ├── FacultyView.jsx # Date-wise attendance logging
│ ├── AdminDashboard.jsx # Defaulter analytics optimized with useMemo
│ └── StudentView.jsx # Personal student breakdown & switcher
├── App.jsx # Root layout wrapping with ThemeProvider
└── index.css

---

## Tech Stack

- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS
- **State Management:** React Hooks (`useState`, `useEffect`, `useContext`, `useMemo`)

---

## User Roles & Features

1. **Faculty Portal:**
   - Daily attendance sheet generation with custom date selection.
   - Subject-wise tracking (Java, Cloud Computing, Data Structures, Machine Learning).
   - Interactive Present/Absent toggles and instant submission feedback.
2. **Admin Analytics:**
   - Institution-wide attendance overview and averages.
   - Automated Defaulter tracking for students falling below the mandatory **75% threshold**.
3. **Student Portal:**
   - Personal attendance breakdown per subject with dynamic calculations.
   - Visual progress bars and automated warning badges for low attendance.

---

## Architecture & Assumptions

- **Single-Page Application (SPA) State Management:** Designed with clean modular component state combined with LocalStorage caching to maintain session data across refreshes.
- **Defaulter Logic:** Automatically calculates percentages dynamically from date-wise logs to flag attendance issues instantly.

---

## How to Run Locally

1. Clone the repository or extract files.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server.

```bash
  npm run dev
```
