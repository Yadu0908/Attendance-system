# Attendance-system

Pre-Drive Product Engineering Assignment.

## 🚀 Overview

A comprehensive, modern web application designed for educational institutions to manage student attendance, track low-attendance defaulters automatically, and provide dedicated portals for Faculty, Administrators, and Students.

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS
- **State Management:** React Hooks (`useState`)

---

## 👥 User Roles & Features

1. **Faculty Portal:**
   - Daily attendance sheet generation.
   - Subject-wise tracking (Mathematics, Physics, Data Structures).
   - Interactive Present/Absent toggles and instant submission feedback.
2. **Admin Analytics:**
   - Institution-wide attendance overview.
   - Automated Defaulter tracking for students falling below the mandatory **75% threshold**.
3. **Student Portal:**
   - Personal attendance breakdown per subject.
   - Visual progress bars and automated warning badges for low attendance.

---

## 🏗️ Architecture & Assumptions

- **Single-Page Application (SPA) State Management:** Designed with clean modular component state to simulate a robust backend session.
- **Defaulter Logic:** Automatically calculates percentages dynamically on every state update to flag attendance issues instantly.

---

## ⚙️ How to Run Locally

1. Clone the repository or extract files.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

```bash
   npm run dev
```
